# Changelog

## 0.4.0 — 2026-10-20

Компоненты продуктовых команд.

- Свой компонент команды (без эмодзи, локальный или из библиотеки команды) больше не помечается сам по себе. Вместо этого навык проверяет, из чего он собран (`product-component`): вложенные компоненты, токены, стили, иконки, самодельные элементы.
- Самодельные лейблы и чипы, кнопки и строки списка внутри компонента команды (`ds-lookalike`) — догадка по структуре, ИИ подтверждает по скриншоту.
- Содержимое проверяется один раз на мастер-компонент, пометка — одна на все копии, со ссылкой на мастер-компонент, если он в этом же файле.
- Кнопки внутри компонентов команды не считаются Primary экрана (`multi-primary`).
- Правила `non-ds` и `local-component` заменены на `product-component`.
- `tools/check.sh`: лимит размера отдельно для каждого скрипта (`annotate.js` дополняется пунктами).

## 0.3.0 — 2026-10-20

Меньше пометок на макете.

- Одна и та же проблема у одного элемента — одна пометка на весь флоу, а не на каждую копию. Элемент — это инстансы одного компонента или копии слоя (то же имя и ширина) на разных экранах.
- В пометке строка «Этот же элемент ещё в N местах — поправь и их» со списком экранов и ссылками на слои.
- Больше 5 разных элементов с одной проблемой на экране — остальные считаются в той же пометке («Та же проблема ещё в N местах у других элементов»).
- Пункты паттернов от ИИ тоже собираются в один пункт на элемент (`more`).
- Автотест: флоу из двух экранов, локальный компонент в 6 местах → одна пометка.

## 0.2.0 — 2026-10-20

Калибровка по ручному ревью «[2.0] Косметик».

- Компоненты 🍋 — платформенные компоненты команды Платформы: не проверяем и не помечаем (раньше были «Проверить»).
- Hex на иконках — ошибка `icon-hex`: переопределение цвета иконки, вектор до 48 px с hex, иконка, собранная вручную (одна пометка на иконку).
- Раздетаченные иконки и иллюстрации (фрейм с именем `Base / 40 / …`) — `detached`.
- Шторка, собранная вручную из 🍏 Bottomsheet Header и фреймов, — `manual-bottomsheet`.
- Паттерны кнопок: порядок по важности сверху вниз (`button-order`), Primary для «Назад» и «Отмена» (`secondary-primary`), несколько Primary на экране (`multi-primary`). Inline button не считается.
- «Красный крест» (иллюстрация Error / Failed) — `illustration-meaning`: ИИ решает по смыслу экрана, нужна ли замена на Warning.
- Пометки про старые стили подсказывают плагин ДС из закрепа DoD ДС.
- `outline.js` показывает иллюстрации внутри компонентов.
- `tools/check.sh` проверяет, что скрипты укладываются в лимит `use_figma`.
